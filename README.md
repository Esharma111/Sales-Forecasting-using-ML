# 📈 Sales Forecasting using ML (Linear Regression, Random Forest, XGBoost)

## 🎯 Objective
To accurately forecast daily restaurant sales using historical transaction data by applying machine learning models and evaluating their performance using RMSE.

---

## 🧩 Steps Performed

1. **Data Preprocessing**  
   Parsed dates, extracted time-based features, and merged three datasets.

2. **Data Cleaning**  
   Handled missing values, removed irrelevant columns and add relevant columns like date, month, year, day_of_week, Total_sale .

3. **Exploratory Data Analysis (EDA)**  
   Visualized trends and relationships between features and sales using plots and descriptive stats.

4. **Observations using EDA**  
  Extract insights about on which day/month sale is on peak.
  Compare the performances of the different restaurants. Find out which restaurant had the most sales and look at the sales for each restaurant across different years, months, and days.

6. **Model Training**  
   Trained three regression models: Linear Regression, Random Forest, and XGBoost.

7. **Model Evaluation using RMSE Metric**  
   Compared model performance using RMSE.

8. **Predictions**  
   Used the best model to predict sales on test data and prepared the final csv file for submission.
